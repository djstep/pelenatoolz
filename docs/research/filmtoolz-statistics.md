# FilmToolz: статистика и аналитика — разбор (10.11.2026)

Источник: уроки модуля «Планирование» — https://www.filmtoolz.ru/lessons/plan/ (тексты и скриншоты уроков). Пересказ своими словами, функциональный референс, не визуальный.

## 0. Карта: где живёт статистика

| Уровень | Где | Что |
|---|---|---|
| Главная проекта | «Общие показатели» + «Аналитика хронометража» | паспорт проекта, полосы прогресса «сделано / план», столбчатый график хронометража |
| Меню «Отчёты, аналитика» | 7 отчётов | Аналитика по проекту · Ежедневные производственные показатели · Отчёт по хронометражу · Хронометраж по сценам · Внутренняя занятость актёров · Ведомость по использованию ресурсов · График сдачи на канал |
| Производственные отчёты | список смен | план/факт по каждой смене + средние переработки |
| Карточки | актёр, персонаж, объект, локация | блок «Статистика» с кликабельными числами |
| Контекстные итоги | либретто, КПП, групповые действия, экспорт | сводка по выделению/фильтру, итоги дня, счётчики смен |

Базовые единицы везде одни: **сцена**, **плановый хронометраж** (из карточки сцены), **смена** (день КПП), **факт** (из производственного отчёта). Страниц/восьмушек в статистике нет.

## 1. Главная страница проекта (дашборд)

- Паспорт: серий × длительность серии, плановая выработка за смену, плановые даты съёмок и число дней, плановое число смен, число групп; кнопка «Настройки проекта».
- Два месяца календаря (текущий день в рамке).
- «Общие показатели» — полосы прогресса вида «сделано / план» (смены, хронометраж и др.). Для них нужны плановые даты, дни и смены в параметрах проекта.
- «Аналитика хронометража» — столбцы: хронометраж по договору (сколько сдать заказчику) → плановый (посчитал планировщик) → снято по плану (плановый хрон снятых сцен) → снято по факту.
- Параметры проекта прямо влияют на отчёты: выработка, серии и длительность, группы, камеры, плёнка (перевод хронометража в метры), город (погода и световой день в КПП).

## 2. Аналитика по проекту (главный отчёт 2-го режиссёра и продюсера)

**Вкладка «Сводные показатели»** — карточки-виджеты:
- кольцевые диаграммы: ИНТ/НАТ (ИНТ, НАТ, НАТ/ИНТ, павильон, не задано) и режим дня (день, ночь, вечер, утро, режим, не задано) — % по плановому хронометражу;
- топ-списки с полосками и %: персонажи, объекты, массовка, групповка, каскадёры, грим, костюм, реквизит, игровой транспорт (по каждой категории ресурсов); у виджета иконка перехода в подробную вкладку.
- Справа — список всех категорий (навигация по вкладкам).

**Вкладка категории** (персонажи / объекты / любой ресурс) — таблица:
- №, название, (для персонажей: актёр, тип роли);
- **Смен по КПП** — фактическое число дней в КПП с этим элементом (две группы в один день = 1 смена);
- **Смен расчётно** = плановый хрон сцен ÷ плановая выработка (25 мин ÷ 7 мин = 3,6); галочка «округлить вверх». Смысл: оценка бюджета ещё до КПП;
- **Сцен** — число и % от всех сцен;
- **Хр-ж план** — сумма и % от общего. Факт в этом отчёте не используется.
- Фильтры: тип роли, диапазон серий, теги и др. Для объектов — «группировать по объектам»: родитель суммирует подобъекты, раскрывается.
- Переключатель версии КПП.
- Экспорт: всё (книга Excel, лист на категорию) / отфильтрованное (активно только при фильтре) / текущая вкладка.

## 3. Отчёт по хронометражу

Сгруппирован по сериям, раскрывается до сцен (или режим «показывать сцены»); диапазон серий.
Колонки:
- дата съёмки (из отчёта смены);
- сценарий план; **сценарий снято** — плановый хрон только снятых сцен (не путать с фактом); факт (из монтажных карточек);
- предмонтаж, монтаж (вводятся на странице «Хронометраж монтаж» в либретто);
- не снято = план − снято(план);
- разницы: факт − план, монтаж − план (по снятым);
- прогнозы: **по факту съёмки** = факт + не снято; **по факту монтажа** = монтаж + факт несмонтированных + не снято.
- Итого + «Итого (серий)» = общий хрон ÷ длительность серии (75:30 при 5×15 → 5,03 серии).
- Переключатель «сцены на досъём считать снятыми / нет». Снятые — зелёная метка, смонтированные — тёмно-зелёная. Меню у сцены: карточка, монтажная карточка.

## 4. Хронометраж по сценам

- Матрица: строка = серия, ячейка = номер сцены, цвет = статус (снято — зелёный, смонтировано — тёмно-зелёный, удалена — серая зачёркнутая, не снято — белая).
- Наведение: план / факт / монтаж; клик — карточка сцены.
- Справа по серии блоки: Всего (сцен, хрон), Снято (сцен, план, факт), Не снято (сцен, хрон), Удалено, Уточнённый хрон (план + разница факт−план снятых). Строка Итого.
- Учёт досъёма — настройка проекта.

## 5. Внутренняя занятость актёров (DOOD)

- Строки: персонаж + актёр; колонки: даты. Ячейка дня занятости — зелёная с «+»; ночная смена темнее с фиолетовым уголком; клик → вызывной дня.
- Слева: смен в выбранном периоде / всего по КПП (две группы в день = 1 смена).
- Сортировка: по числу смен или по алфавиту. Фильтры: имена, серии, тип роли, теги, период; листание месяцев.
- Мини-шкала месяцев: столбик заполнен пропорционально числу съёмок в месяце.
- Версия КПП. Экспорт: таблицей (как на экране) или списком (даты через запятую).

## 6. Ведомость по использованию ресурсов (самый «денежный» отчёт)

Строки: все категории ресурсов, актёры, локации (раскрываются до элементов); колонки: даты месяца. Дни КПП — плашка в шапке (клик → вызывной), ночь затемнена с уголком, сегодня — красная рамка.

Три режима:
1. **Количество** (по умолчанию): у категории — сумма элементов за день. Чёрное число — есть факт отчёта, серое — только план. Фон: зелёный — без переработок, жёлтый — с переработкой (часы в углу), красный — были доп. выплаты. Наведение: план/факт количества, часы и стоимость переработки, километраж.
2. **Стоимость**: в ячейке сумма за смену, всплывающая расшифровка расчёта. Справа — свод за период: смены, переработки, километраж, доп. выплаты. «Подробнее» → страница элемента по сменам («?» = нет данных отчёта, клик → отчёт смены). Галочка «без налога (ФК)».
3. **Сцен в день** — «эффективность» ресурса: доля сцен дня с ним. Зелёный 70–100%, жёлтый 30–70%, красный 0–30%. Наведение: сцены дня (его — выделены), его хрон против общего. У посменных ресурсов — пометка «смена».

Справа в любом режиме: стоимость смены, всего смен, всего количество, часы переработки, итог с разбивкой.
Правила: нет отчёта — только план без переработок; нет длительности смены — 12 ч; финансы видны только при праве на фин. условия (частичное право → прочерки у остального).
Фильтры: месяц/период, тип ресурса, теги, «только задействованные в периоде». Версия КПП. Экспорт — в текущем режиме.

## 7. График сдачи на канал

- Строки: серии + плановая дата сдачи (задаётся в карточке серии); колонки: даты.
- Ячейка = сколько сцен серии ещё не снято на эту дату, прогноз по КПП (будущие дни считаются снятыми вовремя).
- Дата сдачи выделена; дни после неё с остатком > 0 — красные: текущий КПП не позволяет сдать вовремя.

## 8. Производственные отчёты (список смен)

Колонки: дата, группа, № смены группы, тайминг план/факт, длительность план/факт, % план-факт, сцен план/снято, хрон план/снято, переработки (смена / актёры / ресурсы).
- Переработка актёров/ресурсов = сумма часов ÷ число людей с заполненным фактом (11 ч ÷ 15 = 0,7). Смена = минуты переработки ÷ 60.
- Цвет ячейки переработки ярче при большем значении, зелёный — 0, серый с прочерком — нет данных. Итого — среднее по проекту.
- Вызывной сохранён — чёрный шрифт, нет — серый; замок — зафиксирован.
- Внутри отчёта: сцены дня цветом статуса, календарь смен (тёмный — факт внесён, светлый — нет).
- «Ежедневные производственные показатели» — отдельный пункт меню, урока нет; известно, что туда добавляются колонки метража плёнки план/факт.

## 9. Статистика в карточках

- **Актёр**: всего сцен, не снято сцен, хрон всего, хрон не снятых, число объектов; блок «Снято» (сцены x/y, хрон %), календарь смен актёра по месяцам с «прошло смен / всего» и съёмочным периодом.
- **Персонаж**: те же показатели; клик по «не снято» → список этих сцен. В списке персонажей — колонки «смен», «объектов».
- **Объект, локация**: всего сцен, не снято, хрон всего / не снятый; клик → список. Фильтр списков по числу смен.

## 10. Контекстные итоги

- Либретто: выделение или фильтр → сводка (сцен, хрон план/факт); панель групповых действий показывает то же + суммы ресурсов.
- КПП: над календарём «смен в группе / во всех группах» (подсказка по группам), шкала заполненности месяцев с переходом; в шапке дня — № смены, дата, хрон дня, число сцен, погода, рассвет/закат, предупреждения о занятости (и о пересечении групп); при наличии вызывного — начало/конец смены и чистое время съёмки.
- Режим КПП «по объектам» — чтобы видеть число объектов в дне (переезды, передекор).
- Краткий экспорт КПП: на день — сцены, объекты, персонажи, сумма хрона.

## 11. Сквозные принципы

1. Одна шкала: плановый хрон — основа всех долей и прогнозов; факт — только из отчёта смены.
2. «Смена» элемента = день, где он есть (группы не удваивают).
3. Везде: переключатель версии КПП, фильтры с тегами, период, экспорт «как на экране».
4. Drill-down везде: число → список сцен; ячейка → вызывной / сцена / отчёт.
5. Одни цвета статусов во всех экранах: снято — зелёный, не снято — красный, досъём — жёлтый, запланировано — серый, удалено — серый зачёркнутый.
6. План и факт различаются начертанием (серый/чёрный), а не отдельными таблицами.
7. Финансы — только по праву, без права — прочерк, а не скрытая колонка.
8. Настройка «досъём = снято?» влияет на все хронометражные отчёты.

## 12. Слабые места (не копировать)

- Отчёт по хронометражу и «Хронометраж по сценам» в основном дублируют друг друга (разный вид одних данных).
- Сводные показатели игнорируют факт: доли только по плану.
- Нет страниц/восьмушек — только хронометраж.
- Шумные виджеты: кольца с рядами «0%».
- Средняя переработка «на человека» скрывает выбросы (один актёр с 5 ч переработки не виден).
- Дашборд на главной слабо связан с отчётами: пункты открываются через выпадающее меню.
