# Ручная проверка правок по вашему списку замечаний

Где: локально, `http://localhost:3000`, ветка `fix/security-batch` (коммиты `f932db6` … `914ef53`). Вход под своим аккаунтом (продюсер).

**Перед началом — один раз:** остановите `npm run dev` (Ctrl+C), выполните `npx prisma generate`, снова `npm run dev`. Без этого статус «Резерв» не заработает.

База общая с сайтом. Тестовые записи называйте «ТЕСТ», после проверки удалите по списку в конце.

## 1. Роли и участники

Участники и роли:
- [ ] В своей строке вместо выпадающего списка — название роли текстом. Сменить себе роль нельзя.
- [ ] Смените роль второму участнику → всплывает «Роль обновлена». Сразу верните прежнюю.
- [ ] Если сервер отказал (например, «В проекте должен остаться хотя бы один продюсер») → всплывает причина, в списке снова прежняя роль.
- [ ] «+ Добавить роль» → «ТЕСТ роль» → Сохранить → окно закрывается само, всплывает «Роль создана».
- [ ] Откройте «ТЕСТ роль», поменяйте галочку, сохраните → окно закрывается, «Роль сохранена».

Приглашение:
- [ ] Создайте приглашение с ролью «Наблюдатель». В ссылке замените `https://pelenatoolz.vercel.app` на `http://localhost:3000` — **обязательно**, иначе откроется сайт со старым кодом и снова поменяет вам роль.
- [ ] Откройте ссылку → «Принять» → под кнопкой красным «Вы уже участник проекта». Ваша роль не изменилась.
- [ ] Отзовите приглашение.

## 2. Акт: ставка НДС

Контрагенты → Акты → новый акт «ТЕСТ»:
- [ ] Галочка «С НДС» → в «Ставка %» видно «22%». Выберите 5% и 7% — число видно, «Итого с НДС» пересчитывается.
- [ ] Выберите «Другая…», введите 10 → «Итого» считается по 10%. Сохраните, откройте снова → «Другая…» и 10.
- [ ] В списке «Платёж» подписи без лишних запятых.

## 3. Договор

Контрагенты → Договоры → «Добавить договор»:
- [ ] «Тип ведомости»: список широкий, выбранное название видно целиком.
- [ ] Договор «ТЕСТ» с «С НДС» → «Другая…» = 10 → «Итого» по 10%, договор сохраняется. Откройте снова → «Другая…» и 10.

## 4. Комментарии в сценарии

Сценарий → откройте версию с комментарием:
- [ ] Поставьте курсор в строку рядом с карточкой комментария. Значок 💬 стоит на правом краю листа, не на карточке.
- [ ] Клик по полю «Ответ…» срабатывает, можно напечатать. (Тестовый ответ потом удалите.)

## 5. Версии сценария и либретто

Сценарий (список версий):
- [ ] У нетекущей версии рядом с названием кнопка «Сделать текущей». Нажмите → вопрос «Либретто при этом не изменится…» → подтвердите → метка «Текущая» переехала.
- [ ] Верните текущей прежнюю версию тем же способом.
- [ ] Откройте нетекущую версию → в шапке рядом с названием тоже «Сделать текущей».
- [ ] Журнал аудита: есть записи «Текущей выбрана версия сценария …».

Окно «Обновить либретто» (боковая панель редактора). **Кнопку «Обновить либретто» внутри окна не нажимайте**, если не хотите менять сцены:
- [ ] У существующих сцен галочки «обновить» уже стоят на полях, подсвеченных жёлтым (отличаются от либретто). Совпадающие поля без галочки.
- [ ] Измените текст в редакторе, не сохраняя, и нажмите «Обновить либретто» → предупреждение о несохранённых правках. Отмените, верните текст.
- [ ] (По желанию, на тестовой сцене) примените обновление → сообщение «обновлено N» считает только реально изменённые сцены, отдельно «без изменений N».

## 6. Вызывной

Вызывные → любой день:
- [ ] Белый лист в стиле FilmTools: сверху три колонки (день и руководители / времена и цеха / погода, сбор, адреса), ниже актёры и ресурсы.
- [ ] Ниже — альбомное расписание: время, № сцены, хронометраж, режим, объект, синопсис, персонажи, транспорт, примечания; внизу «Итого».
- [ ] На тестовом дне добавьте в «Плане дня» пару слотов (подготовка, сцена, обед) → обед и подготовка — серые строки на всю ширину, сцена — полная строка. Потом удалите слоты.
- [ ] «Печать» → «Сохранить как PDF»: стр. 1 книжная, расписание альбомное, без меню сайта, лист не обрезан.
- [ ] Узкое окно / телефон: верхние колонки встают одна под другой.

Не входит в эту правку: выгрузка PDF/Excel через «Экспорт» — в старом виде.

## 7. Кастинг: «Резерв»

Препродакшн → Кастинг:
- [ ] У кандидата в списке статусов есть «Резерв». Поставьте его тестовому кандидату — сохраняется.
- [ ] (Только на тестовом персонаже) утвердите другого кандидата на ту же роль → кандидат в «Резерве» остался в резерве, остальные — «Отказ».
- [ ] Выгрузка каст-листа: у резервного кандидата статус «Резерв».

## 8. Выпадающие списки (общая правка)

- [ ] Пролистайте пару форм со списками (смета, финансы, КПП): подписи нормальные, выбранное значение видно. Если где-то список стал пустым или «Выберите…» вместо значения — скриншот.

## Что удалить после проверки

- [ ] «ТЕСТ роль» (Участники и роли → Удалить). Отозванное приглашение остаётся в базе, в списке его не видно.
- [ ] Акт и договор «ТЕСТ».
- [ ] Тестовый ответ на комментарий в сценарии.
- [ ] Текущую версию сценария верните как было.
- [ ] Тестовые таймслоты в вызывном.
- [ ] Статус «Резерв» у тестового кандидата; если утверждали — верните карточку тестового персонажа и статусы кандидатов.
