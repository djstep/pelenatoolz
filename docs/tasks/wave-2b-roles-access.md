## Задача 1. Двойной флажок «Снятие фиксации платежей»

Сейчас в редакторе ролей (`src/features/roles/components/permission-matrix-editor.tsx`) этот флажок выводится дважды с одним именем поля: в основной таблице и в блоке «Финансы модуля». Сервер берёт значение первого.

- Оставь флажок в одном месте. Где логичнее — предложи.
- Проверь всю форму роли на поля с одинаковым `name`. Проверяй по отрисованной форме в браузере, а не только по коду. Список — в отчёт.
- Проверка: снять и поставить флажок → сохранить → перезагрузить страницу → состояние совпадает. Правило «нельзя выдать больше, чем имеешь» работает как раньше.

## Задача 2. Окно роли стирает введённое после отказа сервера

Сейчас, если сервер отказал при сохранении роли (например, «Нельзя выдать права шире ваших собственных»), окно сбрасывает название и все флажки.

- Найди причину. Вероятно, это сброс полей при новом ответе сервера, а не только при открытии окна.
- Нужно так: поля сбрасываются только при открытии окна. После отказа введённое остаётся, ошибка видна.
- Пройди остальные окна с тем же механизмом сброса (`useOnChange` / `useActionState`, сброс по ответу сервера). Где та же ошибка — исправь тем же способом. Список проверенных и исправленных окон — в отчёт.
- Проверка в браузере: под ролью с «управлением участниками» (не продюсер) выдать роли право, которого у тебя нет → отказ, название и флажки на месте.

## Задача 3. Журнал: изменения участия в проекте

Сейчас принятие приглашения в журнал не пишется. По трём принятым приглашениям не установить, кто их принял.

- Пиши в журнал: принятие приглашения, отклонение (если оно есть в коде), смену роли участника, удаление участника, возврат участника (повторное приглашение возвращает ту же запись участия). Назначение и снятие главы цеха уже пишутся — проверь.
- Запись — от имени того, кто сделал действие (при принятии — от принявшего).
- В `changes` — id пользователя, роль (название и id). Почт и телефонов не писать.
- Старые записи не восстанавливай.
- Проверка: пригласить второй аккаунт, принять, сменить роль, удалить, пригласить снова. На каждый шаг — запись в журнале.

## Задача 4. Цифры на «Обзоре» по правам

Сейчас карточки «Обзора» (сцены, локации, дни и т.п.) показывают числа всем, без учёта прав.

- Карточка показывается, только если виден её раздел. Условие — то же, что у меню (`NavAccess` из волны 1б), отдельной логики не заводить.
- Для скрытых разделов сервер числа не считает и в браузер не отдаёт. Мало просто скрыть их в разметке.
- Проверка: под продюсером — всё как было. Под ролью без финансов и договоров — нет их цифр, и в данных страницы их тоже нет.

- Данные и таблицы не трогать.
