# Импорт сценария: находки ручной проверки

Записано 7 ноября 2026, при проверке сайта на сервере. Задача после nginx. Первый шаг — только анализ причин,
план и тесты на эти примеры. Код не менять до «ок» владельца.

## 1. Режим не распознаётся, если после него хронометраж в скобках

Примеры заголовков:

- `НАТ. ЗАГОРОДНЫЙ ДОМ — РАССВЕТ (00:15)`
- `ИНТ. ДОМ. КУХНЯ — УТРО (ПОЗЖЕ) (02:05)`
- `ИНТ. ДОМ. ДЕТСКАЯ / КОРИДОР — ДЕНЬ (01:40)`

Сейчас хвост `РАССВЕТ (00:15)` уходит в локацию. После ручного выбора режима заголовок становится
`… — РАССВЕТ (00:15) — РАССВЕТ`.

## 2. Хронометраж «Из файла» равен 0:15

Похоже, берётся только первая сцена, а не сумма. Хронометраж из скобок должен стать хронометражем сцены.

## 3. Режим «Вручную»

Написано «Ручной ввод по сценам», но непонятно, где вводить.

## Результат шага 0

Причины воспроизведены на примерах выше, код не менялся.

### Причины

1. **Режим.** `parseHeading` снимает в конце шапки только скобку-пометку `(ПОЗЖЕ)`. Скобка `(00:15)` остаётся, хвост
   `РАССВЕТ (00:15)` не совпадает со словарём, и вся строка уходит в место.
2. **Итог «Из файла».** По отдельным сценам счёт верный: 0:15, 2:05, 1:40, всего 4:00. Ошибка в итоге сценария:
   если у всех сцен пустой план, `estimateScreenplayTiming` ищет метку во всём тексте, а находит только первую.
   Пустой план бывает, например, после импорта в режиме «Вручную». Какой случай был на сервере, не проверялось.
3. **«Вручную».** Поле есть: карточка сцены в либретто, «Хронометраж сцены», «План». Подсказка на него не указывает.

### План правок

1. `heading.ts`: снимать `(ММ:СС)` в конце шапки раньше пометки, новое поле с секундами.
2. `normalize-script.ts`: передавать секунды из шапки в данные сцены.
3. `review/timing.ts`: в режиме «Из файла» брать секунды из шапки, а не первую метку в тексте сцены:
   иначе `(12:30)` в ремарке может стать хронометражем.
4. `write/plan.ts`: записывать эти секунды в план сцены.
5. `screenplay/lib/timing.ts`: в запасном подсчёте складывать все метки, а не брать первую.
6. Подсказка режима «Вручную»: где вводить, со ссылкой на либретто.

### Тесты

| Вход | Ожидание |
|---|---|
| `НАТ. ЗАГОРОДНЫЙ ДОМ — РАССВЕТ (00:15)` | место `ЗАГОРОДНЫЙ ДОМ`, режим `РАССВЕТ`, 15 с |
| `ИНТ. ДОМ. КУХНЯ — УТРО (ПОЗЖЕ) (02:05)` | место `ДОМ. КУХНЯ`, режим `УТРО`, пометка `ПОЗЖЕ`, 125 с |
| `ИНТ. ДОМ. ДЕТСКАЯ / КОРИДОР — ДЕНЬ (01:40)` | объект `ДОМ`, подобъекты, режим `ДЕНЬ`, 100 с |
| Все три, план сцен пуст, «Из файла» | итог 4:00 |
| Ручной выбор режима после разбора | режим в шапке один раз |
| `(12:30)` в ремарке, в шапке `(00:15)` | хронометраж сцены 0:15 |
| Шапка без скобок | как сейчас |

Тесты добавляются вместе с правками: сейчас они упали бы и остановили общий прогон.

### Вопросы владельцу

1. Убирать ли `(00:15)` из текста шапки в сценарии? Рекомендация: убирать, время остаётся в плане сцены.
2. Записывать ли время из шапки только в режиме «Из файла»? Рекомендация: ещё и в режиме «Вручную» как начальное значение.

### Решение владельца

Время в скобках в конце шапки сцены — всегда хронометраж, и хронометраж пишется только в шапке.
Решение уточнено: текст шапки остаётся как в файле, `(00:15)` из него не убирается. Время только дополнительно
заполняет план сцены: в режиме «Вручную» пустой план, в режиме «Из файла» с вопросом при расхождении.
