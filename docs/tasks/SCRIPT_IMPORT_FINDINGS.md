# Импорт сценария: находки ручной проверки

Записано 7 ноября 2026, при проверке сайта на сервере. Задача после nginx. Первый шаг — только анализ причин,
план и тесты на эти примеры. Код не менять до «ок» владельца.

## 1. Режим не распознаётся, если после него хронометраж в скобках

Примеры заголовков:

- `НАТ. ЗАГОРОДНЫЙ ДОМ — РАССВЕТ (00:15)`
- `ИНТ. ДОМ. КУХНЯ — УТРО (ПОЗЖЕ) (02:05)`
- `ИНТ. ДОМ. ДЕТСКАЯ / КОРИДОР — ДЕНЬ (01:40)`

Сейчас хвост `РАССВЕТ (00:15)` уходит в локацию. После ручного выбора режима заголовок становится
`… — РАССВЕТ (00:15) — РАССВЕТ`.

## 2. Хронометраж «Из файла» равен 0:15

Похоже, берётся только первая сцена, а не сумма. Хронометраж из скобок должен стать хронометражем сцены.

## 3. Режим «Вручную»

Написано «Ручной ввод по сценам», но непонятно, где вводить.

## Шаг 0

1. Найти причины в разборе заголовков и подсчёте хронометража.
2. Составить план правок.
3. Подготовить тесты на примеры выше.
4. Показать план и дождаться ответа владельца.
