# ЧАСТЬ 1. ИНСТРУКЦИЯ

## Что получится

- Раздел «Команда»: все люди проекта по цехам — фамилия, имя, отчество, должность, цех, телефон, почта, заметка. Поиск, группировка по цехам, нажатие на телефон — звонок (на телефоне), на почту — письмо.
- **Подтянуть из договоров**: окно со списком договоров с физлицами/самозанятыми/ИП, которых ещё нет в команде, — отмечаешь галочками, они добавляются с ФИО, должностью и телефоном из договора и контрагента.
- **Добавить вручную** — для тех, у кого договора нет (или ещё нет).
- У человека из договора — пометка «из договора» и кнопка «Обновить из договора»: показывает, что изменится, применяешь или нет. Ручные правки не затираются молча.
- Ушёл с проекта — «В архив» (видно отдельным фильтром), не удаление.
- Экспорт через общий конструктор колонок (Excel, печать) — как в остальных списках.

**Чего не будет.** Связи с вызывным (блок руководителей цехов из команды) — это отдельный шаг позже, когда команда наполнится. Связи «человек команды ↔ аккаунт в системе» — тоже позже.

## Почему копия, а не «живая» связь с договором

Если команда читает договор напрямую, человек без финансовых прав увидит через команду данные договора. Плюс поменяли телефон в договоре — он поменялся бы в команде без ведома. Поэтому как с кастингом: при добавлении данные копируются, обновление — по кнопке с показом разницы.

## Общие правила

- Миграции — только на ветках базы dev и e2e. На прод не применять.
- Изменения данных — через `auditMutation`: добавление (вручную / из договора №…), правка, обновление из договора (какие поля), архив, возврат из архива.
- Права — через существующую систему ролей. Новые права: «Команда: просмотр», «Команда: редактирование», «Команда: контакты» (телефон, почта). Продюсеру и владельцу — все по умолчанию; остальным ролям — только «просмотр» («контакты» и «редактирование» — нет, выдаются вручную в ролях). Без «Контактов» телефон и почта не приходят с сервера вообще (не только скрыты на экране) — ни в списке, ни в карточке, ни в экспорте, ни в поиске (поиск по телефону без права не ищет по телефону). Добавить в матрицу ролей и в журнал изменений ролей, как остальные права.
- Данные договора (номер, сумма, ссылка на договор) в команде видны только тем, у кого есть право на просмотр договоров. Остальные видят только «из договора» без деталей.
- Оформление — компоненты и правила волны 5. Таблица — по правилам таблиц волны 5.
- Не трогать модуль договоров, кроме чтения. Если нужно поле в договоре — спроси.
- Новые пакеты не нужны.

## Шаг 1. Модель и права

`CrewMember` (подстрой имена под стиль проекта):
- `projectId`, `lastName`, `firstName`, `middleName?`, `position`, `departmentId?`, `phone?`, `email?`, `note?`, `sortOrder`;
- `source`: `manual` | `contract`; `contractId?`, `counterpartyId?` — связь только для «Обновить из договора»;
- `syncedAt?` — когда последний раз взято из договора;
- `archivedAt?`, `createdAt`, `updatedAt`, кто создал.

Один контрагент — одна запись в команде на проект (если у него несколько договоров — связь с последним действующим, остальные видны в «Обновить»). Ручная запись может быть потом связана с договором («Связать с договором» — выбор из списка), после связи — обычное «Обновить из договора».

Телефон — хранить как ввели, для ссылки `tel:` нормализовать при выводе. Валидация почты — простая.

## Шаг 2. Экран команды

- Список с группировкой по цехам (без цеха — отдельной группой в конце), сортировка внутри цеха по `sortOrder`, затем по фамилии; перетаскивание для порядка — только если в проекте уже есть такой механизм в похожих списках, иначе стрелки/без ручного порядка — спроси.
- Колонки: ФИО, должность, цех, телефон, почта, источник («вручную» / «из договора»), заметка. Без права «Контакты» — колонок телефона и почты нет.
- Поиск по ФИО, должности, телефону. Фильтр по цеху, «Архив».
- Карточка человека (окно): все поля, «Обновить из договора» (если связан), «В архив». Несохранённые изменения — существующий механизм.
- Пустое состояние: «Добавить вручную» и «Подтянуть из договоров» (вторая — только при праве на просмотр договоров).

## Шаг 3. Из договоров

- «Подтянуть из договоров»: список договоров проекта с физлицами/самозанятыми/ИП, чьих контрагентов нет в команде. Колонки: ФИО, должность по договору, цех, телефон, статус договора. Галочки, «Добавить выбранных». Дубли (совпадение по телефону или ФИО с ручной записью) — пометка «возможно, уже есть: …» с выбором «связать с существующей» / «добавить отдельно».
- «Обновить из договора»: таблица «поле — сейчас — в договоре», галочки по полям, «Применить». Поля, которые меняли вручную после последней синхронизации, не отмечены по умолчанию.
- Договор расторгнут или удалён — у записи пометка, запись остаётся.
- Только для тех, у кого есть право на просмотр договоров **и** «Команда: редактирование».
