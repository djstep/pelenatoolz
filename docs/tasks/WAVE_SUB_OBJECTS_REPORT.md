## Модель

- **Объект и подобъект — строки `Location`.** Объект: `parentId` пусто. Подобъект: `parentId` — объект, `name` — название
  подобъекта, `sortOrder` — порядок внутри объекта. Вложенность один уровень (проверяется в коде). Родитель только из
  того же проекта — составной ключ `(parentId, projectId) → (id, projectId)`; ссылка на себя запрещена (CHECK); объект
  с подобъектами база удалить не даёт.
- **Сцена** — та же `SceneLocation`: привязка к строке объекта — объект целиком, к строкам подобъектов — смежная сцена.
  Сцена с двумя объектами («ДВОР ДОМА / ОПУШКА ЛЕСА») остаётся как есть, с пометкой в карточке.
- **Реальное место** — внутри строк: подобъект со своим адресом — своё место (адрес, координаты, схема вызывного,
  аренда); без адреса — место объекта целиком (`hasOwnPlace`, `placeOf`). Справочник «Площадки» — в бэклоге.
- **Тип ИНТ/НАТ/ПАВ** у подобъекта свой, новый подобъект получает тип объекта.

объекты без подобъектов, новых строк нет, связи сцен не менялись. Пробный прогон — на dev в транзакции с откатом.

## Где видно

- **«Объекты»** (`/locations`): дерево, «⋯» — добавить подобъект, изменить, объединить, удалить; стрелки порядка;
  «адрес (как у объекта)»; удаление объекта с подобъектами — понятный отказ.
- **Объединение:** к оставшемуся переходят сцены, скаут, схема вызывного, строки отчётов смены (ключ `location:<id>`),
  правила словаря, события календаря, фото, точки, ставки; одноимённые подобъекты сливаются. Отказы: разный вид, финансы
  без права, оба в одном отчёте смены, разные статьи сметы при строках отчётов.
- **Импорт и сценарий:** шапка «ИНТ. ДОМ. ДЕТСКАЯ / КОРИДОР» — объект ДОМ, два подобъекта; «/» без пробелов — так же
  (кроме файлов старой записи с «///»); шапка в редакторе сценария создаёт объект и подобъекты.
- **Либретто:** колонка «Объект / подобъекты», «Место» — все реальные адреса; карточка сцены — объект и несколько
  подобъектов, другой объект сцены — пометкой, его привязка сохраняется.
- **КПП:** карточка сцены с подобъектами, фильтр и группировка по объекту; экспорт — все места.
- **Вызывной:** план — «ДОМ. ДЕТСКАЯ / КОРИДОР»; объекты дня — по адресу места; схема подобъекта без адреса — схема
  объекта; восход и закат — по координатам места.
- **Отчёт смены:** аренда — одна строка на реальное место в день; если владелец места сменился, строка переходит на
  новый ключ, факт и начисления не теряются.
