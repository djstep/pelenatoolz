## 5. Univer (смета) — что можно

Версии `@univerjs/*` — все 0.25.1. Создаётся в `smeta-spreadsheet-editor.tsx` (~824–894), тема `defaultTheme`, `darkMode: false`; `.univer-smeta-host` в CSS принудительно светлый. Тема приложения с Univer не связана. Вызов `univerAPI.setDarkMode?.(false)` ничего не делает (такого метода нет) — не чиню, запись.

| Что | Можно? | Как |
|---|---|---|
| Шрифт интерфейса Univer (тулбар, меню) | да | наследуется от контейнера — CSS на `.univer-smeta-host` |
| Шрифт в ячейках | да | `defaultStyle {ff}` листа / `setDefaultStyle`; см. вопрос 3 |
| Шрифт шапок строк/колонок | **нет** | зашит в движке (Helvetica/Arial) |
| Цвета шапок строк/колонок | да | `customizeColumnHeader` / `customizeRowHeader` (публичное API) |
| Линии сетки | да | `setGridLinesColor` |
| Цвет выделения | да | своя тема (`primary` палитра) в `createUniver` |
| Тёмная тема | да, но см. вопрос 2 | `createUniver({darkMode})` / `univerAPI.toggleDarkMode` |
| Своя тёмная палитра холста | **нет** | тёмный режим холста — автоматическая инверсия цветов |
| Смена темы без перезагрузки редактора | только через внутренний сервис | значит — при переключении темы пересоздавать редактор или менять только `toggleDarkMode` |

Документация: https://docs.univer.ai (раздел про темы — не нашёл точный адрес в пакетах, сверю на шаге 6).
