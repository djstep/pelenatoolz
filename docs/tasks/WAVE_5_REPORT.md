## 4. Что не удалось и почему

**Univer (смета).** Таблица оставлена светлой по решению владельца. Через публичное API сделано: акцент выделения (своя палитра `primary`), цвета шапок строк и колонок (только отрисовка, размеры не менялись, в лист не пишется), шрифт интерфейса Univer (наследуется от контейнера).

Не удалось:
- шрифт шапок строк и колонок зашит в движке (Helvetica/Arial), настройка `fontFamily` игнорируется;
- своя тёмная палитра холста: тёмный режим — автоматическая инверсия всех цветов, поэтому не включён;
- в тёмной теме собственная лента и строка формул Univer остаются светлыми: их тёмный вид включается только вместе с инверсией холста;
- цвет линий сетки не менялся: `setGridLinesColor` записывает настройку в лист, а стандартный серый близок к эскизу;
- всплывающие меню Univer, если выводятся вне контейнера, шрифт контейнера не наследуют; внутренние классы Univer не трогались.

**Рамка `--dirty` у изменённых полей:** механизма «поле изменено» у обычных полей нет, логика не добавлялась. Рамка стоит только у «времени вручную» в вызывном.

**Таблицы «одна карточка с тулбаром»:** шапка таблиц единая, но внутри карточки на части экранов осталась вложенная рамка таблицы: убрать её значит менять отступы на каждом экране.

**Кнопки в строке заголовка:** только там, где они уже были в шапке страницы. Кнопки тулбаров экрана (например, «+ Добавить сцену») не переносились — правило владельца.

**Снимок страницы одной утверждённой версии** (`/smeta/:цех/versions/:номер`) есть только на 1440 px из временного проекта (`out/step6/screen-version-1-*.png`): в сиде нет утверждённой версии, её нельзя удалить из проекта. Остальные 66 экранов — в полном обходе.
