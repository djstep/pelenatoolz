# Приёмка — сводный чек-лист (актуален для `main` после волн 1–4)

Собран из отчётов `WAVE_*_REPORT.md`, `WAVE_*_NOTES.md`, `docs/audit/FIX_REPORT_*` и сверен с кодом `main` (`2d5c215`).
Отчёт о прогоне — `ACCEPTANCE_REPORT.md`.

**Роли** (создаёт `scripts/e2e-seed.ts` в проекте «E2E приёмка», пароли — в `.env.e2e`):
- **продюсер** — `e2e-producer`, системная роль «Продюсер», владелец проекта;
- **без финансов** — `e2e-nofin`: всё, кроме «Финансов», фин. условий (актёры, объекты, ресурсы), смет и утверждения вызывных; «КПП и вызывные» — просмотр и правка;
- **без вызывных** — `e2e-nocallsheet`: как «без финансов», но без «КПП и вызывные».

**Колонка «Как»:** «автомат» — проверяет `npm run e2e` (файл теста в скобках); «глазами» — владелец руками; «автомат + глазами» — тест есть, но часть видна только человеку (настоящий Chrome, печать на бумаге, вёрстка).

**Убрано / заменено по сравнению со старыми проверками волн:** старый «Вызывной PDF» и «Контакты по цехам» (удалены в волне 3); сохранение спецтранспорта «удалить всё + создать» (`saveTransportsAction`) — теперь построчно по id; «Печать» в окне с `onclick` внутри страницы (2б) — печать вызывается из открывшего окна; подвал «лист N из M» у вызывного (убран перед слиянием волны 3).
