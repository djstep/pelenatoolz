## Задача 1. Меню проекта скрывает разделы по правам

**Сейчас:** меню показывает все разделы, без прав пользователь попадает на «Нет доступа».

**Нужно**
- Пункт меню виден, только если у роли есть хотя бы просмотр этого раздела.
- Права читать той же функцией `parsePermissionMatrix`, что и сервер. Отдельной логики не заводить.
- Фильтр сделать **расширяемым**: каждый пункт меню описывается условием видимости (функция от прав и контекста пользователя), а не только флагом матрицы. В волне 2 к пункту «Сметы» добавится условие «глава цеха», которое не является флагом матрицы.
- Раздел, к которому ведут несколько прав (например «Контрагенты»: справочник — финансы,
  договоры — `contracts`), виден, если есть любое из них.
- Если пользователь открыл скрытый раздел прямой ссылкой — как сейчас, «Нет доступа» с сервера.
  Серверные проверки не трогать.
- Продюсер видит всё, как раньше.

**Проверка:** под продюсером, под ролью «только просмотр договоров», под ролью без финансов и без
договоров, под ролью с одним разделом. Скриншоты меню для каждой роли — в отчёт.

## Задача 2. «Сохранить» в вопросе при переходе по меню

**Сейчас:** при переходе по меню с несохранёнными изменениями в вопросе только «Остаться» и
«Не сохранять».

**Нужно**
- Сделать в общем механизме (`src/shared/ui/unsaved/`), а не в каждой форме: форма регистрирует
  функцию сохранения, которая возвращает успех/ошибку; механизм по «Сохранить» вызывает её и
  переходит только после успеха.
- При ошибке сохранения — остаёмся на месте, ошибка показана в форме, перехода нет.
- Пока идёт сохранение — кнопки вопроса неактивны, повторный клик не отправляет второй раз.
- Формы, которые не зарегистрировали сохранение, работают как сейчас (без «Сохранить»).
- Подключить на страницах-формах из волны 1: настройки проекта, карточка
  сцены, карточки персонажа и локации, показатели дня отчёта смены, редактор сценария.

**Проверка:** в каждой из этих страниц — правка → меню → «Сохранить» → данные сохранены и переход
состоялся; правка с ошибкой валидации → «Сохранить» → остались, ошибка видна.

## Задача 3. Подтверждение удаления комментария в сценарии

- Крестик «Удалить» в карточке комментария спрашивает подтверждение, тем же окном, что удаление
  акта. Текст: «Удалить комментарий?» / «Удалить» / «Отмена».
- Заодно пройди по программе: все кнопки удаления без подтверждения — перечислить в отчёте и
  добавить подтверждение тем же окном. Исключение — удаление строк, которое отменяется сразу
  (если такое есть) — перечислить, не трогать.
