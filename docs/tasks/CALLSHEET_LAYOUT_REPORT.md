### Расхождения по блокам (до правок)

Заполненный день по составу, порядку и виду блоков почти совпадает с макетом. «Беднее» лист из-за того, что прятались все пустые блоки и поля: на пустом дне оставались шапка и погода, на дне с одной сценой — только «Актёры» и «План».

| Блок | Что было | Сделано |
|---|---|---|
| Шапка: сбор и место | нет времени или адреса — плашки сбора нет вовсе | всегда; пустое — «не указано» |
| Полоса времён | только заполненные, ширина «плавает» | всегда 5 полей, как в макете; пустое — «не указано» |
| Погода / объекты / ограничения | пустая колонка пропадает, соседние растягиваются | всегда три колонки; пустое — «не указано» (в макете у ограничений — «нет») |
| Погода: описание | из прогноза: «Пасмурно, -1…2°C, осадки 27%, осадки 27%» — температура дублирует «днём / ночью», осадки повторяются | как в макете: «Пасмурно, осадки 27%»; t — только полями «днём / ночью» |
| Руководители, вызов цехов | пустой блок пропадает, второй растягивается на всю ширину | всегда рядом; пустой — заголовок и «не указано» |
| Актёры, план | пустой блок пропадает | всегда; пустой — заголовок и «не указано» |
| Важно, база, групповка, элементы, 2-й юнит, схема | пустые не выводятся | без изменений (необязательные) |
| Порядок блоков | как в макете | без изменений |

### Где лист по-прежнему отличается от макета (решения волны 3, владелец оставил как есть)

- Листы 2+: бегущая шапка — полем страницы (`@page`), а не отдельной строкой HTML; на экране лист один, без разрывов.
- Колонка таблицы, пустая во всех строках, скрыта (например, «Прибытие» у групповки).
- Сетка «днём / ночью / восход / закат» — компактная, а не растянутая на колонку.
- Пустая «Парковка» на схеме не печатается (в макете — серая подсказка).
- Подвала «проект · дата · смена / статус · версия · лист N из M» нет — решение владельца 03.11.2026 (подвал был добавлен по п. 1 ниже и убран веткой `fix/callsheet-no-footer`): статус и версия — в шапке первого листа.

   Подвал — поле страницы CSS (`@page` → `@bottom-left` / `@bottom-right`, номера — `counter(page)` / `counter(pages)`). Его рисует браузер только при печати, на экране (просмотр на странице) подвала нет. Где работает:
   - **Chrome / Edge / Яндекс Браузер** (Chromium 131 и новее) — да, и в окне печати, и в «Сохранить как PDF». В окне печати Chrome должна быть снята галочка «Колонтитулы» (подсказка уже есть на странице вызывного): с ней Chrome печатает свои колонтитулы (адрес, дату), и подвал листа может не выйти. Бегущая шапка листов 2+ работает так же, с волны 3.
   - **PDF через Chromium на VPS** (Puppeteer / Playwright `page.pdf()` или `chrome --headless --print-to-pdf`) — да: проверено `npm run preview:callsheet` (`chrome --headless=new --print-to-pdf --no-pdf-header-footer`), в PDF на листе 1 — «ИРП · вызывной на 11.09.2026 · смена 40» и «лист 1 из 3», на листе 3 — «лист 3 из 3».    - **Firefox и Safari** полей страницы CSS не поддерживают — лист печатается без подвала и без бегущей шапки (остальное — как есть). Если нужен подвал и там — только через PDF, собранный на сервере.
2. **Руководители**: фамилия (первое слово ФИ) — жирным, имя — обычным, как в макете; одно слово — целиком жирным. В печати — `<b>Фамилия</b> Имя`, в Excel (и Google Таблице) — rich text в ячейке.

## 2. Правило пустых блоков

`src/features/call-sheets/print/print-blocks.ts` — одно правило для печати, просмотра на странице (тот же HTML) и Excel / Google Таблицы:

- обязательные, всегда: шапка (время и место сбора), полоса времён, погода, объекты, ограничения по актёрам, руководители, вызов цехов, актёры, план;
- необязательные, только если заполнены: «Важно», база и транспорт, групповка, элементы, второй юнит, схема;
- пустое поле обязательного блока — «не указано» серым.

Модель листа и отпечаток данных не менялись (в модели по-прежнему только заполненные времена) — старые снимки утверждённых версий печатаются по новому правилу, плашка «данные изменились» от этой правки не появится.

## 3. Excel (и Google Таблица на диске)

`print-xlsx.ts` строит блоки по тому же списку и в том же порядке, что печать: обязательные — всегда, «не указано» серым; необязательные пустые — нет. Google Таблица на диске — из этой же книги (`drive-actions.ts`). Денег в листе нет: e2e проверяет `findLeaks` (ставка км спецтранспорта дня 4 есть в базе, в листе и книге — нет).
