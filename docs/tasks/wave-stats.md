# ЧАСТЬ 1. ИНСТРУКЦИЯ

## Что получится

1. **Одни и те же цифры везде.** Итог дня, хрон и страницы персонажа или объекта, число смен — один расчёт на всю систему. Сейчас итог одного дня считают четыре функции по разным правилам.
2. **Отчёт «Аналитика»** (Отчёты → Аналитика): доли ИНТ/НАТ и режимов, топы и таблицы по персонажам, объектам и ресурсам. Сцены, страницы, хрон, снято / не снято, смены по КПП, смены расчётно.
3. **Итоги в рабочих экранах:** сводка в либретто по фильтру и выделению; блок «Итог дня» в отчёте смены.
4. **Отчёт «Хронометраж»:** план → снято → факт → монтаж, прогноз итогового хрона.
5. **Обзор проекта:** паспорт проекта и прогресс съёмок (смены, сцены, страницы, хрон) со ссылками на отчёты.

Референс — разбор FilmToolz (`docs/research/filmtoolz-statistics.md`). Это функциональный референс, не визуальный. Опись того, что есть сейчас, — `docs/tasks/STATS_INVENTORY.md`.

## Правила расчёта (решено)

| Правило | Как |
|---|---|
| Вырезанная сцена | Не входит ни в один итог: хрон, страницы, число сцен, смены элемента, доли. Если она стоит в дне КПП, в шапке дня и в итоге дня — метка «вырезанных: N». *Заменяет решение волны 4 «считается, пока стоит в дне».* |
| «Снято» по дню / смене | Из отчёта этого дня (история попыток съёмки), не из текущего статуса сцены |
| «Снято» по сцене, персонажу, объекту, ресурсу | Из текущего статуса сцены |
| Досъём | «Требует досъёма» = не снято (как «не снято») |
| Число сцен | Разных сцен. Сцена в двух днях = одна сцена |
| Смена элемента | Рабочий (съёмочный) день КПП, где есть хотя бы одна невырезанная сцена с этим элементом. Несколько групп в один день = одна смена |
| Объект → подобъекты | Итог объекта = разные сцены всех его подобъектов (сцена на двух подобъектах одного объекта считается один раз) |
| Смены расчётно | Плановый хрон ÷ плановая выработка за смену; галочка «округлять вверх». Выработка не задана → «—» и ссылка на настройки |
| Доли (%) | От итога проекта без вырезанных сцен |
| Деньги | Только с правом на финансы; без права — прочерк, не скрытая колонка |
| Форматы | Хрон — общий форматтер M:SS; страницы — как сейчас в КПП |

## Не в этой волне

- **Серии как сущность** с плановой датой сдачи и отчёт «График сдачи». Серия остаётся номером у сцены; итоги по номеру серии будут.
- **Версии КПП.** Когда появятся, в отчёты добавится переключатель версии.
- **Теги** у сцен, ресурсов и дней.
- **Единый расчёт денег** (налог, округление, копейки в 5–7 файлах) — отдельная короткая задача с reviewer. Здесь деньги только показываются готовыми функциями.
- Сетка занятости актёров по дням — если её нет, шаг 0 скажет; решим отдельно.

## Общие правила

- Один модуль расчёта: `src/features/stats/`. Чистые функции (без базы, с юнит-тестами) + слой выборок. Экраны не считают итоги сами — только вызывают модуль. Старые копии расчётов удаляются, когда экран переведён (список — в отчёт).
- Правила — строго по таблице «Правила расчёта» в части 1. Каждое правило — отдельный юнит-тест с говорящим названием.
- Запросы: агрегирование в базе или одна выборка на экран; никаких запросов в цикле по сценам или дням. На тяжёлом проекте (генератор из волны 11, если есть; иначе 200+ сцен, 40 дней) — число запросов и время ответа страницы до и после в итог шага.
- Права — существующие. Отчёт или вкладка видны, только если есть право просмотра соответствующего раздела (сцены, персонажи, объекты, ресурсы). Деньги — только с правом на финансы, без права — прочерк. Проверка на сервере, не только в интерфейсе.
- Открытие отчётов ничего не пишет в базу и журнал. Экспорт пишется в журнал без сумм (кто, что, фильтры) — как в волне смет.
- Графики — без новых пакетов: CSS-полосы и простой SVG. Цифра всегда текстом рядом, смысл не держится только на цвете. Цвета — переменные темы, обе темы. Спокойные цвета, не кислотные.
- Экспорт — ExcelJS, `excelSafe`, числа остаются числами.
- Тексты — русские. Существующие тексты не менять без причины (на них завязаны e2e).
- Оформление — компоненты `src/shared/ui`, правила волны 5, разделы страницы — каждый в своей карточке.
- Живые данные на проде: миграции только добавляют необязательные поля, ничего не пересоздаётся.
- Не рефакторить «заодно». Новые пакеты и миграции — только после моего «да».

## Шаг 1. Единый расчёт

## Шаг 2. Отчёт «Аналитика»

Страница `/reports/analytics` (путь — по принятому в проекте), пункт в меню «Отчёты».

- **Сводка** (первая вкладка): ИНТ/НАТ и режимы дня — горизонтальная 100%-полоса с подписями и % (по плановому хрону; рядом — число сцен); топ-5 по каждой категории (персонажи, объекты, каждая категория ресурсов) — полоса + % хрона; у карточки — переход во вкладку.
- **Вкладки категорий:** персонажи (актёр, тип роли — если есть в данных), объекты (дерево объект → подобъекты, раскрывается; итог объекта — по правилу), локации, ресурсы по категориям. Колонки: сцен (N, %), страницы (%), хрон план (%), снято сцен, не снято сцен, неснятый хрон, смен по КПП, смен расчётно (галочка «округлять вверх»). Сортировка по колонкам.
- Клик по числу сцен / неснятых — переход в либретто с этим фильтром (или окно со списком — по решению шага 0).
- Фильтры: номер серии (диапазон), ИНТ/НАТ, режим, «только с неснятыми». Фильтры — в адресе.
- Экспорт Excel: «всё» (лист на вкладку) и «текущая вкладка с фильтрами».
- e2e: аккаунт с правами на сцены без ресурсов — вкладки ресурсов нет, прямой запрос — отказ; числа персонажа совпадают с его карточкой.

## Шаг 3. Итоги в рабочих экранах

- **Либретто:** строка-сводка над таблицей — для текущего фильтра и, если есть выделение, для выделенных: сцен, страницы, хрон план, хрон факт, снято / не снято. Вырезанные — по правилу (отдельно «вырезанных: N», если попадают в фильтр).
- **Отчёт смены:** блок «Итог дня» (отдельная карточка вверху): сцен по плану / снято / не снято / досъём; страницы; хрон план / факт; время смены план / факт; переработки — сколько человек, сумма часов, наибольшая; деньги за день (начислено) — только с правом на финансы. Ничего не пишет при открытии.
- **Список отчётов смен:** если нет колонок «сцен план / снято», «хрон план / факт», «переработки» — добавить, расчёт из модуля.

## Шаг 4. Отчёт «Хронометраж»

Страница рядом с «Аналитикой».

- Строки — номера серий (если у сцен серий нет — одна строка «Весь проект»), раскрываются до сцен.
- Колонки: дата съёмки (для сцены), план, снято (план снятых), факт, до монтажа, монтаж, не снято (план неснятых), факт − план, монтаж − план, прогноз по съёмке (факт снятых + план неснятых), прогноз по монтажу (монтаж смонтированных + факт снятых несмонтированных + план неснятых). Строка «Итого»; если в настройках есть длительность серии — «серий по плану / по прогнозу».
- Статус сцены — цветной маркер + текст (снято / не снято / досъём / смонтировано), вырезанные не показываются в итогах (фильтр «показать вырезанные» — серыми, вне итогов).
- Экспорт Excel. Пояснение формул — подсказка у заголовков колонок.

## Шаг 5. Обзор проекта

- **Паспорт:** плановая выработка, серии × длительность (если сериал), плановые даты съёмок, плановое число смен, число групп — ссылка «Настройки».
- **Прогресс:** смены прошло / в КПП / по плану; сцены снято / всего; страницы снято / всего; хрон снято / план — полосы с цифрами.
- **Хронометраж:** короткая полоса план → снято (план) → снято (факт) → монтаж.
- Ссылки на «Аналитику», «Хронометраж», «Использование ресурсов», отчёты смен.
- Если плановых дат или планового числа смен нет в настройках — сначала покажи миграцию (необязательные поля), жди «да».
