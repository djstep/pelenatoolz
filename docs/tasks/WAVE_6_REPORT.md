## Скрипт сброса пароля

```bash
npm run user:reset-password -- почта@example.com
```

```bash
npm run user:reset-password -- почта@example.com --env-file .env.prod --prod
```

Пароль генерируется и выводится один раз, в базе только хеш. В журнале запись без пароля. Человек выходит со всех устройств, блокировки снимаются, ссылки сброса гаснут.

Адрес базы берётся только из файла, значения из оболочки игнорируются. `--prod` обязателен, если в файле прод, и запрещён, если не прод. Без `--env-file` используется `.env`. Если указанного файла нет, Node останавливается сам, с текстом `not found`, это тоже отказ. Флаг с таким именем Node читает раньше скрипта.

На настоящем проде скрипт не запускался. Запуск с `--prod` проверен на поддельном адресе: защита пропускает, а до базы дело не доходит.

### После переезда на VPS

Скрипт запускается на самом сервере, из папки приложения. `.env.prod` на компьютере тогда не нужен, и его нужно удалить.

```bash
npm run user:reset-password -- почта@example.com --prod
```

Перед этим нужно проверить две вещи:

- **Метка прода.** Скрипт узнаёт прод по `ep-steep-sound` в адресе (`PROD_HOST_MARK` в `src/features/auth/lib/reset-password-cli.ts`). Если база уедет с Neon, метку надо заменить на новый адрес. Иначе скрипт не увидит прод и откажет с `--prod`, а без флага сработает без защиты. Та же метка стоит в `scripts/e2e-seed.ts` и `e2e/helpers/db.ts`.
- **`tsx` на сервере.** Это пакет разработки. Если зависимости ставятся без него, команда не запустится.

## Решения владельца

- **Согласие у уже зарегистрированных не собираем.** Перед переездом на VPS база будет полностью очищена, все пройдут регистрацию заново и дадут согласие.
- **Миграции на прод** применяются до слияния, с разрешения владельца, как в прошлых волнах.
- **Экран «Забыли пароль»** показывает обращение к администратору, файлы формы оставлены для 6б.
- **Список частых паролей:** SecLists 10k-most-common, лицензия MIT, источник в шапке файла. В файл вошёл 51 пароль от 10 символов и 62 русских варианта.

## Что учесть

- **Посторонний может заблокировать чужую почту.** Для этого нужно 20 неудач с нескольких IP каждые 15 минут, настоящий человек тогда не войдёт. Это обратная сторона лимита на почту. Разблокирует скрипт владельца.
- **Подбор с многих адресов.** Лимит на почту его ограничивает, но по одной почте остаётся около 80 попыток в час. При длинных паролях этого мало для подбора, а старые короткие пароли остаются до смены.
- **Настоящий IP на VPS.** Берётся последний адрес из `x-forwarded-for`. На сервере nginx должен дописывать или ставить его сам. Без этого адрес сможет подставить посетитель, либо все окажутся на одном IP с общим лимитом.
- **Заглушка на проде.** До текста юриста на `/ru/privacy` виден текст «Нужен текст юриста».
- **Редкий сбой a1.** Тест выгрузки КПП упал один раз на шаге 3: кнопка «Экспортировать Excel» 30 секунд оставалась неактивной. Причина не найдена. Не повторился ни в трёх повторах самого теста, ни в четырёх следующих полных прогонах a1, включая полный e2e. По решению владельца, если повторится, разобрать до слияния.
- **Запуск e2e.** `-g c1` или `c1` в имени совпадает и с `c10`–`c14`, поэтому файлы надо указывать полным путём.
