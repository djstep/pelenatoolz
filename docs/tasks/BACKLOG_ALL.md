## 5. Функции (бэклог)
- **Сериальный учёт** (после волны «Статистика», если будет сериал): серия как отдельная запись (номер, плановая дата сдачи, длительность); отчёт «График сдачи» — на каждую дату сколько сцен серии не снято по КПП, красным после даты сдачи. До этого серия — номер у сцены, итоги по номеру уже есть в отчётах.
- **Правила оформления сценария для корректного импорта** — памятка для авторов/редакторов (и подсказка в окне импорта): формат шапки (номер. ИНТ./НАТ. ОБЪЕКТ. ПОДОБЪЕКТ — РЕЖИМ (хронометраж)); подобъект — через точку; смежные места — через «/»; хронометраж — только в скобках в шапке; строка-перечень персонажей сразу под шапкой (имена заглавными через запятую); реплика — имя заглавными, затем текст; голоса за кадром — «ИМЯ (ЗК)»; список режимов; что делать со старой записью («КВАРТИРА/СПАЛЬНЯ///КОРИДОР»). Делается в пакете «Мелочи».
- Несколько версий КПП (после — переключатель версии в отчётах статистики). Первая в очереди функций.
- Справочник «Площадки» (одна реальная площадка на несколько сценарных объектов).
- Удаление сценария по ролям.
- Блок руководителей цехов в вызывном из «Команды» (после наполнения команды; телефон — только с правом на контакты).
- Договор ↔ строки сметы — только отметка, к каким строкам относится договор (суммы — через начисления).
- Календарь: переход сразу на нужный день в «Пробах» и КПП; напоминания, ICS-подписка, повторяющиеся события (после почты).
- Запись пробы: обычное поле времени вместо свободного текста.
- Команда: экспорт с учётом фильтров, экспорт в журнал, настоящий PDF, связь с аккаунтами.
- Видео: перекодирование HEVC → H.264 (сначала выяснить, что за «кодирование в фоне»).
- Пробы: понятное сообщение «файл больше 512 МБ».
- Регистрация: не показывать «Регистрация закрыта» над рабочей формой адресам из allowlist.
