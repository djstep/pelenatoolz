## Сценарий

### Таблица версий: время в колонке «Дата» расходится на 3 часа

В таблице версий сценария (`src/features/screenplay/components/screenplay-versions-list.tsx`, колонка «Дата») время форматируется через `Intl.DateTimeFormat` без пояса: сервер рисует в UTC (15:52), браузер — в своём поясе (18:52). Из-за расхождения React перерисовывает таблицу при загрузке (ошибка гидрации в консоли). Сделать как в журнале: время в поясе проекта, готовая строка с сервера (`formatAuditTime` в `src/features/audit/lib/audit-time.ts`). Замечено при правке `fix/script-import-characters` (10.11.2026).
