## Права

**Разделы бывших «Сцен»** (каждый — просмотр и правка):

- **«Сценарий»** — версии, импорт и синхронизация с либретто, словарь, сравнение, «Файлы» проекта, ссылки облака, загрузка файлов.
- **«Сцены (либретто)»** — либретто, номера сцен, выгрузки либретто и режиссёрского сценария, персонаж из карточки сцены.
- **«Объекты и места»** — объекты, подобъекты, схема, скаут; фин. колонки — ставки объектов.
- **«Ресурсы»** (бывшие «Прочие ресурсы») — «Настройки → Ресурсы»; фин. колонки — ставки категорий без своей строки.
- **«Персонажи»** — без кастинга. Кандидаты, их телефоны и агенты, карточка и снимок утверждённого актёра — только с «Актёрами»; без них видно лишь имя утверждённого актёра.

**Правила, добавленные в волне:**

- Быстрое создание «по названию» — из раздела, который человек правит; пустая запись, детали — только с правом на свой раздел:
  - персонаж — из либретто, сценария или персонажей;
  - объект и подобъект — из либретто или объектов;
  - место из шапки — из сценария или объектов;
  - ресурс — из либретто или ресурсов.
- Удаление персонажа, у которого есть кандидаты кастинга, требует ещё и «Актёры: правка»; окно подтверждения говорит, сколько кандидатов удалится. Без кандидатов хватает «Персонажи: правка».
- «Сметы — вернуть на доработку» — вернуть главе ту смету, которую видишь. Утверждает только Продюсер.
- «Сметы — настройки» — переменные, резерв, агентские, справочники сметы. Правка начислений и платежей («Финансы») их больше не даёт.
- Импорт и синхронизация сценария — по «Сценарий: правка» (меняют и либретто, персонажей, объекты).

## Шаблоны ролей

Обычные роли с ключом шаблона `presetKey`: Продюсер может их переименовать, изменить, удалить. Права — `src/features/roles/role-presets.ts`, ожидаемые права по ролям — `role-presets.test.ts` (`EXPECTED`). Всем — «Команда» без контактов. Ни у одного шаблона нет ролей и участников, настроек проекта, настроек сметы, утверждения смет, снятия фиксации платежей.

| Роль | Правит | Видит |
| --- | --- | --- |
| Режиссёр-постановщик | сценарий, кастинг и пробы | либретто, КПП, вызывные, объекты, персонажи, календарь |
| 2-й режиссёр | либретто, КПП, вызывные (+ утверждение), персонажи и занятость, календарь, отчёты смены | сценарий, кастинг, объекты, команду с контактами |
| Помощник режиссёра (хлопушка) | отчёты смены | сценарий, либретто, КПП, вызывные, календарь |
| Оператор-постановщик | смету своего цеха (глава цеха) | сценарий, либретто, КПП, вызывные, объекты, календарь |
| Художник-постановщик | смету своего цеха, объекты и скаут | сценарий, либретто, КПП, вызывные, календарь |
| Художник по костюмам, Художник-гримёр | смету своего цеха | сценарий, либретто, персонажи без кастинга, КПП, вызывные, календарь |
| Директор картины | договоры (без сумм), команду с контактами, объекты и ресурсы со ставками, календарь | все сметы и план/факт, финансы, КПП, вызывные |
| Линейный продюсер | договоры, начисления и платежи | все сметы (может вернуть главе), всё остальное со ставками, команду с контактами, постпродакшн |

## Приглашение

- **Быстрый выбор роли.** Кнопки шаблонов над списком ролей, описание выбранной роли.
- **Поле «Глава цеха».** Необязательное. У четырёх ролей «смета своего цеха» — подсказка выбрать цех. Если цехов нет — ссылка на «Настройки → Цеха».
- **Кто может указать цех.** Только тот, кто может назначать глав (Продюсер или управление участниками — как в «Цехах»), и только цех этого проекта. Роль шире своих прав выдать нельзя (как и раньше).
- **Принятие.** Человек становится участником с ролью и главой цеха в одной транзакции. Принять можно только действующее приглашение — повтор и отзыв в ту же секунду дают отказ.
- **У цеха уже есть глава.** Прежний не снимается. Форма показывает нынешних глав, журнал пишет «прежние главы остаются: …».
- **Цех удалили до принятия.** Человек вступает без цеха, в журнале — «вступил без цеха: цех «…» удалён». Это видно и на странице приглашения, и в списке приглашений.

## Решения владельца

- **Шаг 0:**
  - разделить «Сцены» (вариант Б);
  - новая галочка «вернуть на доработку» — у Линейного продюсера;
  - Директору картины — просмотр финансов и правка ставок объектов и ресурсов;
  - «настройки сметы» — отдельное право, по умолчанию только у Продюсера;
  - всем — команда без контактов, 2-му режиссёру — утверждение вызывных, хлопушке — календарь;
  - похожих ролей на проде нет.
- **Шаг 1:**
  - удаление персонажа с кандидатами — только с «Актёры: правка»;
  - быстрое создание — из раздела, который правишь;
  - импорт — по «Сценарий: правка»;
  - описания персонажей в версии сценария — ок.
- **Шаг 2:** смены и серии в параметрах проекта, «настройки сметы» без «Финансов», возврат главой своей сметы — оставить как есть.
- **Шаг 3:** Директор картины правит договоры без сумм — только поправить описание; окно выкатки — ок.

## Замечено, не чинилось

- Галочки «Импорт сценария» и «Хронометраж монтажа» по-прежнему ничего не дают.
- Время в списке версий сценария на сервере и в браузере расходится (часовой пояс) — предупреждение при загрузке страницы; было и до волны.
- Журнал принятия приглашения и создания приглашения пишется после транзакции (прежняя схема).
- Миграция описания «Директора картины» не пишет запись в журнал проекта.
