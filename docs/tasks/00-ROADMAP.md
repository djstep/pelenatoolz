# Пакет правок после волны 5 — порядок и решения

Положить все файлы пакета в `docs/tasks/`. Каждая волна — отдельный файл в формате волны 5: часть 1 для тебя, часть 2 — промпт для Claude Code (самодостаточный, сессия начинается с `/clear`).

## Решения, которые нужны от тебя (по умолчанию — первый вариант)

Каждый файл спросит их на шаге 0, но лучше решить заранее:

1. **Почтовый сервис** (волна 6): **решено — Resend**, бесплатно (3 000 писем в месяц, 100 в день), через SMTP. Перед реальными людьми — замена на российский сервис (Unisender Go) настройками, без кода: Resend зарубежный, адреса пользователей уходят за границу.
2. **Домен отправителя** (волна 6): с какого адреса уходят письма (например `noreply@mail.povpro.ru`). Без своего домена Resend шлёт только на твою почту. Нужен доступ к DNS домена — записи выдаст Resend.
3. **Вход без подтверждённой почты** (волна 6): нельзя, пока не подтвердил. Существующие и тестовые аккаунты помечаются подтверждёнными миграцией.
4. **Кто видит телефоны в «Команде»** (волна 8): **решено** — только с правом «Команда: контакты» (по умолчанию у владельца и продюсера).
5. **Объединения разделов** (волна 7): мои предложения — в файле волны 7, Claude Code на шаге 0 сверит их с реальным меню и покажет таблицу. Решаешь по таблице.
6. **Какие экраны должны полностью работать на телефоне** (волна 10): матрица в файле волны 10, утверждаешь на шаге 0.

## Риски, которые я вижу

- **Персональные данные.** Волны 6 и 8 добавляют почты и телефоны людей в базу. До прихода реальных пользователей нужны: согласие на обработку персональных данных при регистрации (галочка + текст политики) и хранение данных в России — переезд на VPS в РФ это закрывает, Neon и Vercel — нет. Сейчас база тестовая, поэтому не блокирует, но **реальных людей пускать только после переезда**. Текст политики — к юристу, не к Claude Code.
- **Ограничение попыток входа на Vercel.** В бессерверной среде память между запросами не живёт, счётчик попыток должен лежать в базе. На VPS можно будет вынести в Redis — не обязательно.
- **Объединение вкладок не должно менять адреса.** Иначе ломаются ссылки в письмах-приглашениях, закладки и e2e. В файле волны 7 это заложено (группы маршрутов Next.js без смены URL).
- **Связь «Команда ↔ Договоры».** Если команда читает договоры «вживую», человек без финансовых прав сможет увидеть данные договора через команду. Поэтому в волне 8 — копия на момент добавления + кнопка «Обновить из договора», как с кастингом.
- **Оптимизация через VPN к Neon меряет VPN, а не код.** Поэтому в волне 11 считаем число запросов к базе и размер страниц, а не миллисекунды. Миллисекунды — после VPS.
