## Риски

- **Живые данные на проде.** Любая миграция только добавляет необязательные поля, проекты не пересоздаются.
- **Персональные данные.** Прод в РФ — закрыто. Остаются согласие при регистрации, реквизиты в политике, трансграничная передача (Google Диск, геокодер, YouTube) — раздел 10 бэклога.
- **Рамка в рамке (5б).** Разделы внутри окон и карточки сцены — плоские блоки, не карточки. Список мест — шаг 0 волны.
- **Объединение вкладок не меняет адреса** — правило остаётся для всех следующих волн (ссылки в приглашениях, закладки, e2e).
