# ЧАСТЬ 1. ИНСТРУКЦИЯ

## Что получится

- **Разделы читаются с первого взгляда.** Каждый раздел формы или страницы лежит в своей карточке: в светлой теме белая карточка на «бумаге», в тёмной `#222` на `#1B1B1B`. Рамка, скругление 12. В шапке карточки значок, название, счётчик и действие справа.
- **Четыре уровня текста вместо одного.** Заголовок страницы, заголовок карточки, категория внутри карточки и подпись поля больше не выглядят одинаково.
- **Меньше шума.** Нет плашки «Название / Кол-во», когда колонок две. Нет строки-заглушки в пустом разделе: там стоит «—». Добавлять можно одним способом: «+ Добавить» в строке заголовка категории.
- **Спокойный цвет по смыслу, одинаковый на всех экранах.** Синий — основное, сроки, документы. Фиолетовый — люди. Песочный — вещи и структура. Бирюзовый — деньги. Цвет только в мелочах. Не больше двух смысловых оттенков на экран.
- **Статусы** показаны точкой и словом. Обычное состояние — просто точка со словом, без плашки.

**Чего не будет.** Функции, поля, тексты, права, адреса и данные не меняются. Миграций нет. Печатные листы и файлы (вызывной, явочный, сценарий-бумага, Excel) не трогаются. Сетка сметы (Univer) не трогается, меняется только оболочка вокруг неё. Доска КПП не перестраивается: правила волны 5 остаются, меняются только статусы.

## Решения (приняты 11 ноября)

| Вопрос | Решение |
|---|---|
| Вариант | A: разделы в карточках, внутри строки на всю ширину |
| «Описание» | Синим. Бирюзовый — только деньгам |
| Оттенки | Не больше двух смысловых оттенков на экран. Статусы и ссылки не считаются |
| Песочный текст в светлой теме | `#855600`. Проверить на реальном экране; если читается плохо — `#7A4D00` |
| Поля ввода в светлой теме | Чисто белые по токенам волны 5 (`--surface`), не `#FAFAF8` как на эскизах |

**Следствие правила двух оттенков.** На карточке сцены обычно три категории: описание (синий), люди (фиолетовый), вещи (песочный). По правилу один оттенок уходит в нейтральный. По умолчанию нейтральным становится синий, если на экране есть и люди, и вещи. Тогда «Описание» синее только там, где ему хватает места в двух оттенках. Claude Code на шаге 0 покажет таблицу экранов, где это срабатывает. Решаешь по таблице.

## Правила оформления

### Карточка раздела

- Новый компонент `SectionCard` в `src/shared/ui` (имя — по принятому в проекте): фон `--surface`, рамка `--border`, скругление 12, тень `--glass-shadow`, внутренний отступ 16, между карточками 16.
- **Шапка карточки:** значок в плашке 24×24 (скругление 6, фон — мягкий тон категории, значок 14 px того же тона), название 15 px / 650, счётчик (если число уже есть в данных) — мелкая плашка в тоне категории, действие справа («+ Добавить» призрачной кнопкой или меню «⋯»). Высота шапки 44, линия `--border` под шапкой, если у карточки есть тело.
- **Внутри — строки на всю ширину**, как сейчас. Линия между строками `--border`.
- **Категория внутри карточки** (например «Грим» в «Ресурсах»): 14 px / 650, рядом приглушённое количество (`--muted-fg`), справа «+ Добавить». Это единственное место добавления в категории.
- **Пустой раздел или категория:** заголовок, «—» (`--muted-fg`) и «+ Добавить». Без строки-заглушки и без текста вида «Нет данных», если он не нужен e2e (если нужен — оставить текст, приглушённым).
- **Плашка названий колонок** — только когда колонок три и больше.
- **Полоса «Итого»** (где она есть): фон — мягкий тон категории, подпись — в тоне, числа `--foreground`, `tabular-nums`.

### «Рамка в рамке»

Окна, выезжающие панели и карточка сцены уже лежат на поверхности. Внутри них разделы — **не карточки**, а плоские блоки: та же шапка (значок, название, счётчик, действие), без рамки и тени, разделены линией `--border` и отступом 20. Карточки внутри карточек не допускаются нигде. Спорные места — в таблицу шага 0.

### Смысловые цвета

Новые переменные, обе темы:

- Цвет **только в мелочах**: плашка значка, счётчик, надпись группы, полоса «Итого». Текст, поля, кнопки, подписи полей — нейтральные.

### Правило двух оттенков

- На одном экране (странице, окне, карточке сцены) — не больше двух смысловых оттенков из четырёх. Статусы, ссылки, фокус и предупреждения не считаются.
- Если категорий больше двух: оттенок сохраняют две категории с наибольшим числом разделов на экране, остальные получают нейтральную плашку значка. При равенстве первым в нейтральный уходит синий, потом песочный. Деньги на финансовых экранах всегда бирюзовые.
- Таблица по экранам — в шаге 0, решаю я.

### Статусы

- Вид: точка 6–8 px + слово. Обычное, ожидаемое состояние («Активен» и подобные) — точка + слово **без плашки**. Остальные — плашка (мягкий фон тона, скругление 5) с точкой и словом.
- Тона: «В КПП» и другие «в плане, в работе» — синий; «Подписан», «Утверждён», «Снято» и прочее «готово» — зелёный (`#1E8A47` / `#5BD08A`); «Черновик», «Приглашён», «Ожидает» — песочный; ошибка, отказ, просрочено — `--danger`; «Вырезана» — как сейчас (серый + зачёркивание).
- Слова статусов не меняются. Полная таблица «статус → тон» — в шаге 0. Где по смыслу подходят `--tone-*` волны 5 — переиспользовать, не плодить переменные.
