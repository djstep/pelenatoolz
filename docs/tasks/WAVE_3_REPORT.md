## 4. Решения владельца

- **Шаг 0:** шрифт — официальный файл (стал Medeo Sans вместо IBM Plex в 3а); координаты — одно поле «Координаты»; 2-й юнит — дорожка в плане, строки руками; спецтранспорт — статья у строки, сохранение по id; «утверждение» — только «Продюсеру»; при утверждении — снимок модели листа (`CallSheetApprovedVersion`); шаблон вызывного правит «КПП и вызывные: правка»; старые данные не переносятся.
- **Шаг 2:** ставка км — только с «Финансы: правка» и нигде не выводится на лист; одинаковые элементы из разных сцен — максимум, не сумма; раздел вызывного у категории ресурсов — настройкой категории (по умолчанию — по точному названию), без раздела — «Прочее»; новые разделы «Грим» и «Спецэффекты»; посменные ресурсы — строками в элементах; тайминги актёров — по обоим юнитам; схема объекта — пока `script:write`.
- **Шаг 3а:** реквизит в строке сцены плана выводится (костюм, грим, спецтранспорт — нет); ФИ руководителей без выделения; хронометраж «11′40″».
- **Шаг 3б:** явочный лист «Цеха» — из вызывного; лист на странице маршрутом, шрифт файлом; новое правило `excelSafe` (телефоны и «+6°» без апострофа).
